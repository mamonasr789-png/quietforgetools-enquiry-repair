Case
Northstar Plumbing — DEMONSTRATION
Offer
£149 Enquiry Path Repair — one bounded defect
Reported issue
Contact form appears to submit; owner never receives the enquiry email
Report type
Written diagnostic + repair + verification note (async delivery)
1 · Symptom

What the site owner reported

  • Visitors on the Contact page can fill Name, Phone, Message and press Submit.
  • The form shows a success/thank-you state in the browser.
  • No matching enquiry appears in the intended business mailbox (enquiries@northstar-plumbing.example).
  • Issue reproducible on desktop and mobile; no visible error message to the visitor.
2 · Diagnosis

Checks performed (least-privilege temporary access)

  • Confirmed the public Contact form still posts successfully (HTTP 200 / plugin success response).
  • Inspected form notification settings: “Mail sent to” and “From” addresses.
  • Compared notification recipient against the mailbox the owner monitors daily.
  • Sent one controlled test submission and traced where the notification was delivered.
  • Ruled out a broken Submit button and a front-end validation loop (visitor path completed).

Finding: the form pipeline was completing for the visitor; the failure was in notification routing, not in the submit UI.

3 · Root cause

One bounded defect

Contact Form 7 (or equivalent) notification was still addressed to a retired staging address:

wp-admin+staging@oldhost.example

instead of the live mailbox enquiries@northstar-plumbing.example. Submit succeeded; the enquiry never reached the monitored inbox. This is one clearly defined enquiry-path defect within the £149 scope.

4 · Repair

Change applied

  • Updated the form’s notification “To” address to the agreed live mailbox.
  • Set a sensible From / Reply-To consistent with the site domain (no password changes; no new plugins).
  • Left unrelated forms and site design untouched.
  • Documented the single configuration change in this completion note.
5 · Verification

How repair was checked

  • Submitted a labelled test enquiry from the live Contact page (desktop).
  • Confirmed the notification arrived in enquiries@northstar-plumbing.example within normal mail delay.
  • Repeated one mobile-width submission; same delivery result.
  • Confirmed the visitor still sees a clear confirmation state after Submit.

Result: agreed enquiry path delivers to the monitored mailbox. No claim is made about enquiry volume or sales.

6 · Handover

What you receive / what happens next

  • This written note — symptom, diagnosis, root cause, change made, verification steps.
  • 7-day defect support — if this agreed repair regresses within 7 days, that regression is fixed under the same offer.
  • Access removed — temporary collaborator / staging access used for the repair is revoked when work is complete. You keep ownership of the site and content. Passwords are never requested by email.
Outside this £149 pass

Not included (quoted separately if needed)

  • Redesign, rebrand, or CRO programmes
  • Multiple independent defects on other forms or pages
  • New CRM / automation stacks or multi-location routing
  • Guarantees of more enquiries or revenue
